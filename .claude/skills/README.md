# Claude Code skills

Project skills Claude Code loads automatically from this folder.

| Skill | What it does | Source |
|---|---|---|
| `taste-skill` | Better design direction — anti-slop rules for landing pages, portfolios, redesigns | [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) (MIT) |
| `web-design-guidelines` | Audit your UI against Vercel's Web Interface Guidelines, reports `file:line` issues | [vercel-labs/agent-skills](https://github.com/vercel-labs/agent-skills) |
| `awesome-design` | 70+ real design systems (Stripe, Linear, Vercel, Apple…) as references | [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) (MIT) |
| `image-to-code` | Turn a screenshot / mockup / design reference into code | [djd933/claude-design-plugins](https://github.com/djd933/claude-design-plugins) (MIT) |
| `playwright-cli` | Let Claude open the site, inspect, screenshot and test the UI | [microsoft/playwright-cli](https://github.com/microsoft/playwright-cli) (Apache-2.0) |

`playwright-cli` needs the CLI on your PATH: `npm install -g @playwright/cli@latest`
(or run it ad hoc with `npx @playwright/cli`).
